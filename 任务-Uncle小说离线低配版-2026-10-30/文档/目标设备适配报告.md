# 目标设备适配报告（DTPC953）

> 文档版本：v1.0（2026-10-30）｜适用对象：Uncle小说 离线低配重构版（基于 v5.0.44 增强版）
> 依据材料：本任务 [`README.md`](../README.md) §1/§3；目标设备原始取证文件（DxDiag / AIDA64 / CPU-Z / MSInfo32）
> 状态约定：设计口径已定、但尚未在目标机或受限 JVM 下实测的条目，统一标注 **「待 Lead 实测确认」**；不得把设计值当作实测值引用。

## 1. 结论摘要

1. **能运行，但必须按低配档运行**：DTPC953 为 ASUS PN40 迷你机（Win10 1809 LTSC x64 / Celeron J4005 2 核 2 线程 / 4GB 内存 / 128GB SSD / 1080p@96DPI），满足 Java 11 + JavaFX 17 的运行条件；但 **无显卡驱动（Microsoft 基本显示适配器）、无声卡、可用内存仅约 667MB**，属于"可跑、不能按普通办公机配置跑"的设备。
2. **本版已实施的低配适配**：JVM 收紧到 `-Xmx512m`（快速阅读 `-Xmx448m`）、JavaFX 强制软件渲染、关闭翻页动画与页面阴影、下载线程降至 1、关闭书架自动更新、关闭更新检查与分析上报，阅读窗口按 1080p/96DPI 定为 1120×760 / 字号 22 / 行距 0.25。
3. **间歇联网与老板键是本版两个行为级改造**：离线/在线状态后台探测 + 标题标识 + 统一提示框 + 恢复自动启用；完整版与本地 TXT 快速阅读两种模式均注册全局老板键（默认 `Alt+U`）。
4. **主要不确定性**：① Win10 1809 + JavaFX 17 软渲染组合尚未在真机实测；② 启动耗时/内存占用（RSS）尚未采样；③ 域环境（Symantec Endpoint Protection、代理/组策略、VNC 远程维护）可能影响联网探测与安装脚本执行。以上均列入 §5 风险与 §7 验证状态表，由 Lead 实测回填。

## 3. 逐项影响分析

| 目标机约束 | 具体影响 | 对软件的要求 | 当前对策（本版） |
|---|---|---|---|
| **Win10 1809 / 17763** | JavaFX 17 自带 WebKit，不依赖系统 WebView2；但 1809 无 UWP/新版组件，输入法与字体渲染较新系统旧；官方 v5.0.44 未在 1809 验证过 | 不依赖商店组件；关闭更新检查；避免使用新版 Windows API | JDK 11.0.18 + JavaFX 17.0.2 内嵌 runtime；`-Duncle.update.check=false`；目标档跳过更新/埋点 |
| **Celeron J4005 2C2T** | 单线程性能弱，启动 JVM+JavaFX 与建章节索引都吃 CPU；并发线程多会互相抢占 | 控制启动路径、减少后台线程、避免动画与阴影 | `-XX:+UseSerialGC`；下载线程 1/重试 1；关闭翻页动画、页面阴影、书架自动更新 |
| **4GB 内存（可用 667MB 级）** | 默认 `-Xmx1024m` 会挤压系统；Chrome/Symantec 同时运行时空闲内存接近耗尽，触发换页 | 收紧堆/元空间/代码缓存；避免大缓存 | `-Xms64m -Xmx512m -XX:MaxMetaspaceSize=192m -XX:ReservedCodeCacheSize=96m`；快速阅读 `-Xmx448m` |
| **无 GPU 驱动（基本显示适配器）** | JavaFX 默认优先 D3D，失败才回退 sw；驱动缺失时回退过程可能黑屏/白屏数秒；有硬件驱动时软渲染帧率更低 | 强制软件渲染；降低界面复杂度 | `-Dprism.order=sw -Dprism.forceGPU=false -Dprism.lcdtext=false`；关闭动画/阴影；阅读窗口 1120×760 |
| **无声卡（无默认播放端点）** | TTS 朗读/有声播放会抛底层音频异常或"无声音"；用户容易误判为软件故障 | 入口处前置检测并提示，不输出异常堆栈 | `OfflineGuard.guardAudio/guardTts` → 「音频不可用」提示框（标题「音频不可用」、按钮「知道了」） |
| **SSD 128GB（C: 剩 50.2GB）** | 安装约 146MB + 章节索引/TTS 缓存/下载书会持续增长 | 缓存可控、可清理；安装不落系统目录 | 数据集中在安装目录 `caches/ downloads/ logs/`；部署指南要求 C 盘剩余 ≥10GB |
| **1080p / 96DPI** | 150% 缩放假设会让窗口超出屏幕；字号偏小默认 20 号在 22" 1080p 上略小 | 窗口与字号按 100% 缩放设计 | 阅读窗口 1120×760、字号 22、行距 0.25、书名常显；完整版沿用 940×660 默认窗口 |
| **间歇联网** | 网络随时断/恢复；断网时点联网功能若直接请求会长时间转圈或报错 | 后台探测、UI 标识、入口拦截、恢复自动启用、可手动重试 | `OfflineGuard`：离线 15s/在线 60s 复检；标题「（离线）」/「 · 离线」；联网功能统一提示框；恢复 Toast；「重试联网」 |

## 5. 风险与限制

| 编号 | 风险 | 可能表现 | 等级 | 缓解 / 备注 |
|---|---|---|---|---|
| R1 | **1809 兼容性未真机实测** | 启动失败、白屏、WebView 页面渲染异常、输入法/字体异常 | 中 | 部署前先跑 `目标机环境自检.ps1` + 首次启动验证清单；异常时保留 `logs/` 供 Lead 定位 |
| R2 | **软件渲染性能** | 首屏出现慢（数秒）、翻页/滚动掉帧、窗口拖动卡顿、长文本分页计算慢 | 中 | 已关闭动画/阴影、窗口 1120×760、字号 22；建议单窗口使用、不边下载边阅读 |
| R3 | **4GB 内存余量（667MB 级）** | 启动/打开大 TXT 时换页、Chrome+Symantec 同开时明显卡顿；极端情况 OOM | 高 | 堆已收紧到 512/448MB；使用前关闭 Chrome 等大内存程序；不并发开多个大文件；异常查 `logs/log-error.log` |
| R4 | **无音频设备** | 朗读/有声播放点了没反应或提示音频不可用（预期行为） | 低 | 入口已前置提示；本地阅读/下载不受影响 |
| R5 | **字体加载** | 若安装/移动到含中文或含空格路径，内置 PingFang 可能加载失败（日志 warn，界面回退系统字体） | 低 | 默认安装路径为 ASCII；保持从快捷方式（起始位置=安装目录）启动；界面字体用系统自带微软雅黑 |
| R6 | **首次启动时无网络** | 首次启动即离线：标题显示「（离线）」、出现离线 Toast、联网入口弹提示框；首次启动本身仍会生成 `logs/`、`caches/` 等 | 低 | 属正常行为；更新检查已在目标档关闭，不应出现"检查更新失败"等待 |
| R7 | **杀软 / 域策略** | Symantec EP 扫描/拦截 exe、bat、ps1；组策略限制脚本执行；PowerShell 执行策略拦截安装脚本 | 中 | 安装脚本统一用 `-NoProfile -ExecutionPolicy Bypass`；被拦截时由 IT 加白名单；安装本身不需要管理员权限 |
| R8 | **代理/网络探测限制** | 域网需代理/认证才能出网时，后台 HEAD 探测可能判为离线，联网功能被拦截 | 中 | 实际 `launcher.vmoptions` 已带 `-Djava.net.useSystemProxies=true`（跟随系统代理）；若系统代理需认证或探测 URL 不可达，可用 `-Duncle.network.probe.url` 改探测地址（部署方配置）；界面点「重试联网」复测 |
| R9 | **VNC / 远程会话** | 远程会话下渲染、截图、全局热键行为可能与本地控制台不同（如热键被远程工具截获） | 低 | 验收尽量在本地控制台进行；远程验收需在报告中注明会话方式 |
| R10 | **磁盘与缓存增长** | 书源规则/章节索引/TTS 缓存/下载书持续写入安装目录；长期可能在 C 盘累积 | 低 | 部署前确认 C 盘 ≥10GB 可用；定期清理 `caches/`（阅读索引会重建）、备份 `conf/` |

> 说明：R1/R2/R3 三项只有真机实测才能定论，当前为基于硬件与配置的工程判断，**不得写成"已验证"**。

## 6. 目标机部署前自检清单

### 6.1 自动自检：`目标机环境自检.ps1`

在解压目录（或安装目录）运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "目标机环境自检.ps1"
```

脚本默认在**脚本同目录**输出 `目标机自检报告.txt`（UTF-8；可用 `-OutFile` 指定路径），逐项给 `[OK]` / `[WARN]` / `[FAIL]`，结尾打印结论行；退出码 `0` = 通过、`2` = 存在不满足项、`1` = WMI 读取失败。核对清单（判定规则按当前脚本实现）：

| 报告输出项 | DTPC953 期望 | 脚本判定规则 |
|---|---|---|
| 操作系统（Caption / 版本 / Build） | Win10 企业版 LTSC 2019 x64，`10.0.17763.x` | 版本号以 `10.*` 开头 → `[OK]`；**不校验 1809 小版本**，Build 只打印，需人工核对 |
| 系统型号 | ASUSTeK PN40 | 只打印，不判定（人工核对是否为目标机） |
| 处理器 | Celeron J4005 / 2 核 2 线程 | 逻辑处理器 ≥2 → `[OK]` |
| 物理内存 | ≈4GB（可识别 3.82GB） | ≥3.5GB → `[OK]` |
| 显示适配器 | Microsoft 基本显示适配器 | 一律 `[OK]`，文案标注「基本显示适配器（已启用 JavaFX 软件渲染，正常）」；有硬件驱动也通过 |
| 音频设备 | 无（未装声卡驱动，无默认播放端点） | 无设备 → `[WARN]`（提示朗读/有声播放不可用；属正常预期，不算失败） |
| C 盘剩余空间 | ≥10GB（实测 50.2GB） | >10GB → `[OK]` |
| 屏幕分辨率 | 1920×1080 | 只打印，不判定（DPI 需人工确认 96/100%） |
| 网络适配器 | 在线/离线均可，离线为正常预期 | 存在已启用网卡 → `[OK]`；无 → `[WARN]`（离线正常） |
| 结论行 | 通过（允许带 `[WARN]`） | 无 `[FAIL]` → `[OK] 全部关键项通过`；有则 `[FAIL] 存在 N 个不满足项` |

> 说明：自检脚本只做**阈值判定**（OS 主版本、CPU 逻辑核数、内存 ≥3.5GB、C 盘 >10GB），型号/Build/分辨率/网络明细为打印+人工核对项；Symantec、域策略、代理等不在脚本范围，由 §6.2 人工清单覆盖。以上规则按 2026-10-30 版脚本实现核对，最终以交付包内脚本为准。
