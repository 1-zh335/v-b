# Uncle小说 离线低配版 · 使用说明书（目标机 DTPC953）

> 版本：v5.0.44 离线低配版（基于官方 5.0.44 + 增强补丁制作）
> 适用系统：Windows 10 1809 x64（目标机 DTPC953：ASUS PN40 / Celeron J4005 / 4GB / 无独显 / 无声卡）
> 安装位置：`%LOCALAPPDATA%\Programs\UncleNovel`（当前用户目录，**无需管理员权限、无需另装 Java、无需联网**）
> 配套文档：[目标设备适配报告.md](目标设备适配报告.md) ｜ [离线部署指南.md](离线部署指南.md)

## 1. 这个版本有什么不同

| 特性 | 本版做法 | 对使用的影响 |
|---|---|---|
| 可离线安装运行 | 安装包内嵌 Java 运行时与全部程序文件 | 断网也能装、能读本地 TXT |
| 低配优化 | JVM 收紧、软件渲染、关动画/阴影、下载线程降为 1 | 启动与翻页比普通电脑慢一些，但更省内存、不卡死 |
| 离线/联网感知 | 后台检测网络，标题加「（离线）」，联网功能点击有统一提示 | 断网时不会长时间转圈/报错 |
| 全局老板键 | 默认 `Alt+U`，完整版与本地 TXT 快速阅读都有效 | 一键隐藏全部窗口，再按恢复 |
| 无 GPU 适配 | 强制软件渲染（`prism.order=sw`） | 首次打开可能有短暂白屏，属正常 |
| 无声卡适配 | 朗读/有声播放入口先检测音频设备 | 点了会提示「音频不可用」，不报错 |

## 2. 安装（离线、免管理员）

1. 把 `Uncle小说-离线低配版-DTPC953.zip` 拷到目标机（U 盘或网盘），**解压到本地盘纯英文路径**（例如 `D:\Uncle离线版`）。
   - 不要直接双击压缩包里的程序运行；不要解压到 `C:\Program Files` 或网络盘。
2. 双击解压目录里的 **`安装到本机.bat`**，等待出现多条 `[OK]`（正常安装约 10 条；快捷方式会因**桌面**和**开始菜单**各建一套而重复出现）。
3. 安装成功的标志（文案以脚本实际输出为准）：

| # | 预期输出 | 含义 |
|---|---|---|
| 1 | `[OK] 程序文件已复制到: ...\UncleNovel` | 程序与内嵌运行时已复制完成 |
| 2 | `[OK] 已生成目标机调优配置: ...\conf\conf.json` | 已写入低配档默认设置（字号/行距/关动画等） |
| 3 | `[OK] 完整版快捷方式: ...\Uncle小说.lnk` | 桌面与开始菜单出现「Uncle小说」（约 2 条） |
| 4 | `[OK] 本地TXT快速阅读快捷方式: ...\Uncle小说 · 本地TXT快速阅读.lnk` | 快速阅读入口（约 2 条） |
| 5 | `[OK] 已加入右键『发送到』菜单: ...\SendTo\Uncle小说快速阅读.lnk` | 右键 TXT 可直接"发送到"本软件 |
| 6 | `[OK] 目标机环境自检脚本已放入安装目录` | 安装目录出现 `目标机环境自检.ps1` |
| 7 | `[OK] 离线/老板键说明已放入安装目录` | 说明文件已就位 |
| 8 | `[OK] 卸载脚本与使用说明已放入安装目录` | 可正常卸载 |

4. 覆盖安装（升级）时：程序文件会更新，**`conf\core.db`（书架）与 `conf\conf.json`（设置）会保留**；仍建议先备份整个 `conf\` 目录。
5. 若脚本提示复制失败：检查磁盘空间、是否被杀毒软件拦截、压缩包是否解压完整。

## 3. 两种启动方式

### 3.1 完整功能版：桌面「Uncle小说」

用于书架管理、书源搜索、解析下载、听书等完整界面。联网功能需要网络；离线时仍可看书架与已下载/导入的书。

### 3.2 本地 TXT 快速阅读（离线首选）：桌面「Uncle小说 · 本地TXT快速阅读」

打开本机 TXT 即读，不需要联网。三种打开方式：

| 方式 | 操作 |
|---|---|
| 文件选择框 | 双击桌面「Uncle小说 · 本地TXT快速阅读」→ 在文件选择框里选 TXT（标题「选择要阅读的 TXT 文件」） |
| 拖拽 | 把 TXT 文件直接拖到安装目录下的 `本地TXT快速阅读.bat` 上（或拖到该快捷方式图标上） |
| 右键发送到 | 右键 TXT 文件 → 发送到 → 「Uncle小说快速阅读」 |

打开过程：识别编码（UTF-8 / GBK / GB18030）→ 识别章节（支持 `第X章`、`=== 标题 ===`、《书名》第X章 等；识别不到按每 10KB 虚拟分章）→ 后台建章节索引（大文件首次较慢）→ 进入阅读器。

## 4. 阅读器操作

| 操作 | 方式 |
|---|---|
| 翻下一页 / 上一页 | 键盘 `→` / `←`；或点击页面右侧 3/4 区域 / 左侧 1/4 区域 |
| 打开章节目录 | 点击页面**最左侧边缘**（约 2% 宽）；或点顶部目录按钮 |
| 调整阅读效果 | 阅读页「设置」面板：字体、字号、行距、页面宽度、对齐、简繁互转、主题背景、翻页动画 |
| 标题栏分页信息 | 形如 `书名 · 章节名（第 2/7 页 · 章 1/331）`；离线时末尾追加 ` · 离线` |
| 阅读进度 | 自动保存；下次打开回到上次章节/页 |
| 书架 | 用快速阅读打开过的书会自动进入「小说书架」（完整版可见）；首次打开会按书名生成封面 |

> 本版默认档：阅读窗口 1120×760、字号 22、行距 0.25、关闭翻页动画与页面阴影（可在设置面板按喜好微调，但低配机不建议重新开动画）。

## 5. 老板键（隐藏 / 恢复）

**默认热键：`Alt+U`**（可在完整版设置里改，见 5.3）。两种启动模式都有效：

- 完整版：按 `Alt+U` → 隐藏全部窗口，**任务栏与托盘图标一起消失**；再按 `Alt+U` → 全部窗口恢复并回到前台。
- 本地 TXT 快速阅读：按 `Alt+U` → 隐藏阅读窗口；再按 `Alt+U` → 恢复。该模式**没有托盘图标**，隐藏后只能靠热键恢复。
- 隐藏期间应用不退出、阅读进度不丢；启动画面会提示「离线可用 · 老板键 alt U 隐藏/恢复」。

### 5.1 重要提示（无托盘时）

> **快速阅读模式没有托盘/任务栏入口，隐藏后唯一恢复方式就是再按一次老板键。**
> 因此请务必记住快捷键；若热键被其他软件占用，请先改键再使用隐藏功能。

### 5.2 若按了没反应 / 找不到窗口

1. 先确认不是输入法/远程工具占用组合键（换一个组合键试试）。
2. 恢复窗口：再按一次 `Alt+U`（若已隐藏）。
3. 实在无法恢复时，可在任务管理器结束 `javaw.exe` / `Uncle小说.exe` 后重新打开（阅读进度已自动保存，但**不建议把强杀当常规操作**）。
4. 程序启动日志 `logs\log-system.log` 中会记录「老板键已注册: …」或「老板键注册失败」，可据此判断。

### 5.3 修改老板键

| 模式 | 修改方法 |
|---|---|
| 完整版 | 左侧边栏「设置」→「软件设置」→「热键设置」→「老板键」输入框：点输入框后直接按新组合键（如 `Ctrl+Alt+H`），显示「快捷键修改成功」即生效；按 `Backspace` 可清除。下方还有「启用全局快捷键」勾选框（切换后若老板键失效，重启程序即可恢复；**待 Lead 实测确认**） |
| 快速阅读模式 | 用记事本打开安装目录 `conf\conf.json`，把 `hotkey.globalBossKey` 的值改为新组合（如 `"alt H"`），保存后重新启动快速阅读窗口生效 |

> 修改后建议重启一次程序确认；若新组合键与系统/其他软件冲突，程序会回退默认 `alt U`（**待 Lead 实测确认**回退细节）。

## 6. 离线 / 联网

### 6.1 怎么判断当前状态

| 位置 | 在线 | 离线 |
|---|---|---|
| 完整版主窗口标题 | `Uncle小说` | `Uncle小说（离线）` |
| 快速阅读窗口标题 | `Uncle小说 · 本地TXT快速阅读` | `Uncle小说 · 本地TXT快速阅读（离线）` |
| 阅读器标题 | `书名 · 章节名（第 x/y 页 · 章 n/m）` | 同上，末尾追加 ` · 离线` |

后台每 15 秒（离线时）/60 秒（在线时）自动复检一次，不阻塞界面；状态变化时右下角会弹 Toast 提示。若启动瞬间就已判定为离线（探测很快失败且窗口尚未显示），可能不会重复弹「离线模式」Toast，此时以标题的「（离线）」和点击联网功能时的提示框为准（**待 Lead 实测确认**）。

### 6.2 点了联网功能会看到什么

离线时点击「搜索小说」（书源搜索）、「全网搜书」、「寻找有声」、「解析下载」、下载任务的开始/续传、有声小说播放、阅读器「朗读」、书源网络导入、搜索/更换封面等功能，会弹出统一提示框：

- 标题：**离线模式**；副标题：「功能名」需要网络连接
- 正文说明：当前未检测到可用网络（本机为间歇联网环境）；**可继续使用**：本地 TXT 快速阅读 / 导入本地小说 / 书架与阅读进度；网络恢复后在线功能自动启用，无需重启
- 按钮：**「重试联网」**（后台重新探测，结果用 Toast 提示）、**「继续离线」**（关闭提示）

### 6.3 联网恢复后

- 网络恢复后自动切回在线：标题去掉「（离线）」，并用 Toast 提示「网络已恢复，在线功能已启用」，无需重启。
- 也可以点提示框里的「重试联网」立即复测：成功提示「网络已连接，在线功能已恢复」；失败提示「仍未检测到网络，本地阅读不受影响」。
- 离线期间的差异行为：书架自动更新、封面网络下载、软件更新检查、使用数据上报都会跳过（均为正常设计）。

### 6.4 联网功能与本地功能对照

| 需要网络 | 本地随时可用 |
|---|---|
| 「搜索小说」（书源搜索）、「全网搜书」、「寻找有声」、「解析下载」、下载任务 | 本地 TXT 快速阅读 |
| 有声播放、TTS 朗读（另需音频设备） | 导入本地小说、书架阅读、阅读进度 |
| 书籍自动更新、搜索/更换封面、书源网络导入 | 阅读设置、主题、简繁互转、卸载 |

## 7. 无声卡 / 无 GPU 时的表现

| 场景 | 你会看到 | 说明 |
|---|---|---|
| 点阅读器「朗读」/「播放」 | 弹框「音频不可用」：`「朗读」需要音频设备`；正文说明未检测到音频设备；按钮「知道了」 | 目标机无可用音频输出设备（未装声卡驱动）。**本地阅读、书架、下载都不受影响**，不会弹异常堆栈 |
| 点有声小说播放 | 同样给出音频/网络提示 | 目标机无声卡，有声播放不可用属预期 |
| 首次启动 / 打开窗口 | 可能有 1–3 秒白屏后出现界面 | 无显卡驱动，已强制软件渲染（软渲染比硬件加速慢，属正常） |
| 翻页 / 拖动窗口 | 略慢、无阴影动画 | 已关闭阴影与翻页动画以换流畅度 |
| 文字清晰度 | 关闭了 LCD 次像素渲染，个别字号下边缘略软 | 可在阅读设置里换字号/换主题改善观感 |

## 8. 数据与备份

- 所有数据都在**安装目录内**：`conf\`（`conf.json` 设置、`core.db` 书架/书源）、`downloads\`（下载的书）、`caches\`（章节索引、封面、TTS 缓存）、`logs\`（日志）、`backup\`。
- **备份** = 直接复制整个安装目录；**迁移** = 整目录拷走（快捷方式需重建或改路径）。
- 不要从其它目录直接运行 `Uncle小说.exe`，否则会在那个目录生成一套新数据（书架/设置看起来"丢失"）。
- 升级覆盖安装会保留 `conf\core.db` 与 `conf\conf.json`，但升级前仍建议先备份 `conf\`。

## 9. 卸载

运行安装目录下的 **`卸载.bat`**（或解压包内的同名脚本），按提示确认两次：

1. 「确认卸载 Uncle小说」→ 选 `Y`：删除桌面/开始菜单快捷方式与右键"发送到"项（脚本对每个删除项打印 `[OK] 已删除 …`）。
2. 「是否同时删除安装目录（含书架/设置/下载，不可恢复）」→ 选 `Y` 才会删除安装目录；选 `N` 只卸快捷方式、保留数据。

> 删除安装目录前请先备份 `conf\core.db`（书架）、`conf\conf.json`（设置）与 `downloads\`（下载的书）。若提示"部分文件被占用"，请先退出软件再手动删除。

## 10. 常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 双击图标没反应 | 先结束任务管理器里的 `Uncle小说.exe` / `javaw.exe`（程序单实例）再试；仍不行看 `logs\log-error.log` |
| 启动慢、先白屏 | 目标机无 GPU 驱动，软件渲染较慢；首次 1–3 秒白屏正常，第二次启动更快 |
| 老板键按了没反应 | 组合键被占用/输入法拦截；按 5.3 改键后重启；查 `logs\log-system.log` 中「老板键已注册」 |
| 隐藏后找不到窗口 | 再按一次老板键恢复；快速阅读模式无托盘，只能靠热键 |
| 一直显示「（离线）」 | 确认网络是否连通；域网可能需代理；点联网功能→「重试联网」，或等 15–60 秒自动复检 |
| 网络已恢复但仍提示离线 | 点「重试联网」，或等待在线复检；仍不行请让维护人员查代理/防火墙 |
| 点朗读提示「音频不可用」 | 目标机无声卡，正常现象；阅读/下载不受影响 |
| 朗读/播放没有声音 | 同上（无音频设备），不是软件故障 |
| 提示字体加载失败 / 中文界面异常 | 安装目录含中文或空格；把整个目录移到纯英文路径后重开 |
| 书架或设置"丢失" | 确认从快捷方式启动（起始位置=安装目录）；不要从别处运行 exe |
| 章节数偏少/偏多 | 取决于 TXT 内章节标题格式；识别不到时会按 10KB 虚拟分章，仍可正常阅读 |
| 打开 TXT 乱码 | 程序自动识别 UTF-8/GBK/GB18030；仍乱码请保留样本文件反馈 |
| 安装脚本一闪而过/失败 | 检查是否被杀毒软件拦截、磁盘空间是否足够、压缩包是否解压完整 |
| 覆盖安装会不会丢书 | 不会丢 `conf\core.db`/`conf\conf.json`；但升级前仍请备份 `conf\` |
| 联网功能一点就弹提示 | 当前离线（预期行为）；恢复网络后自动可用 |
| 网页搜索页打不开 | 需联网且受目标机网络环境限制；离线时不可用属正常 |
| 想彻底删除 | 先备份数据，再执行 `卸载.bat` 并手动删除安装目录 |

### 2. 已知限制（如实说明）
- 本机数据不代表 DTPC953 实测；目标机首次数据请用包内 `benchmark.ps1` 采样并回填本表。
- 目标机无显卡驱动 → 已强制软件渲染，界面可能略慢；无音频设备 → 朗读/有声播放弹提示，本地阅读不受影响。
- 老板键默认 `Alt+U`；完整版设置页关闭「启用全局快捷键」会停用，重新勾选即恢复（已修复原实现不重注册的问题）。
- 阅读窗口实际为 1120×760（部分早期文档写 1100×760，以本节为准）；`launcher.vmoptions` 含 `-Djava.net.useSystemProxies=true`（离线无害）。
