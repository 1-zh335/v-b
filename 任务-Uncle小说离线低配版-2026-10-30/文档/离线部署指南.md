# 离线部署指南（目标机 DTPC953）

> 适用产品：Uncle小说 离线低配版 v5.0.44（DTPC953 专用）
> 部署方式：**离线 zip → `安装到本机.bat` → 自检 → 首次启动验证**；安装到当前用户目录，无需管理员、无需另装 Java、安装过程无需联网
> 配套文档：[目标设备适配报告.md](目标设备适配报告.md) ｜ [离线使用说明书.md](离线使用说明书.md) ｜ 设计契约：[`../README.md`](../README.md)

## 1. 交付包结构清单

```
Uncle小说-离线低配版-DTPC953.zip
├─ 安装到本机.bat              # 主安装脚本（GBK/CRLF，双击运行）
├─ 卸载.bat                    # 卸载脚本（删快捷方式，可选删安装目录）
├─ 创建快捷方式.ps1            # 由安装脚本调用：桌面/开始菜单两套快捷方式 + 发送到
├─ 初始化配置.ps1              # 生成目标机低配档 conf\conf.json（已存在则保留）
├─ 本地TXT快速阅读.bat          # 快速阅读启动器（javaw + 低配 JVM 参数 + %* 透传 TXT）
├─ 目标机环境自检.ps1           # 环境自检，输出 目标机自检报告.txt
├─ benchmark.ps1               # 受限 JVM 下启动耗时/RSS 采样
├─ 使用说明-离线版.txt          # 面向最终用户的说明（安装时复制进安装目录）
├─ 离线部署指南.md              # 本文件
├─ 书源-可选/                  # 可选书源规则与说明（沿用上一版；默认已内置 conf\rules.json）
└─ uncle-novel/                # 程序主体（约 147MB，以实际打包为准）
   ├─ Uncle小说.exe            # 完整版启动器（读取 conf\launcher.vmoptions）
   ├─ uncle-novel.jar          # 启动器 jar
   ├─ favicon.ico
   ├─ bin\kindlegen.exe
   ├─ conf\{app.json, core.db, jul.properties, launcher.vmoptions, rules.json}
   ├─ fonts\pingfang-simple-bold.ttf
   └─ runtime\{bin, conf, lib, modules\...}
```

关键文件说明（结构依据上一版产品包与本次构建脚本整理，**最终以交付 zip 实际内容为准，待 Lead 打包确认**）：

| 路径 | 作用 | 部署关注点 |
|---|---|---|
| `uncle-novel\conf\launcher.vmoptions` | 完整版 JVM 参数（`-Xmx512m`、软渲染、目标档等） | 升级会被新包覆盖；如手工改过参数需记录 |
| `uncle-novel\conf\conf.json` | 用户设置（目标档默认值由 `初始化配置.ps1` 生成） | 覆盖安装**保留**；删掉会重置设置 |
| `uncle-novel\conf\core.db` | 书架/书源/进度数据库 | 覆盖安装**保留**；升级前务必备份 |
| `uncle-novel\runtime\modules\app.jar` | 本版补丁的实际替换目标 | 升级前备份；回退时覆盖回去即可 |
| `uncle-novel\runtime\bin\javaw.exe` | 内嵌 JRE（无需系统 Java） | 缺失即安装不完整 |

## 2. 介质拷贝与解压

**U 盘（推荐）**：把 zip 复制到 U 盘 → 目标机复制到本地盘（如 `D:\临时\`）→ 用 7-Zip 解压到**纯英文、无空格**路径（如 `D:\Uncle离线版`）。不要直接在 U 盘或压缩包内运行；不要解压到 `C:\Program Files` 或网络盘 `W:`/`X:`。

**网盘**：下载到本地盘，确认下载完成且大小与交付记录一致（支持断点续传，避免半包；传输损坏是"解压报错"的常见原因）。

**校验（建议必做）**：

```powershell
Get-FileHash "D:\临时\Uncle小说-离线低配版-DTPC953.zip" -Algorithm SHA256
```

与 [`../交付/SHA256.txt`](../交付/SHA256.txt) 比对；解压后目录应包含 §1 清单且 `uncle-novel\runtime\bin\javaw.exe` 存在，缺项说明解压不完整，需重新解压。

## 4. 目标机自检

### 4.1 运行

```powershell
# 在解压目录（安装前）或安装目录（安装后）执行
powershell -NoProfile -ExecutionPolicy Bypass -File "目标机环境自检.ps1"
# 指定报告路径（可选）
powershell -NoProfile -ExecutionPolicy Bypass -File "目标机环境自检.ps1" -OutFile "D:\目标机自检报告.txt"
```

报告默认写到**脚本同目录**的 `目标机自检报告.txt`（UTF-8）。退出码：`0` 通过、`2` 存在不满足项、`1` WMI 读取失败。

### 4.3 判定与归档

- 出现 `[FAIL]`：**暂停部署**，按报告对应项处理后重跑（如磁盘空间、内存）。
- `[WARN]`（音频、离线网络）：属目标机正常特征，记录即可，不影响交付。
- 将 `目标机自检报告.txt` 归档到任务目录（建议 `../测试/目标机自检报告-DTPC953.txt`），并在验收表引用。
- 自检**不覆盖**：Symantec/域策略、代理、杀毒误拦、VNC 会话等——这些由 §5 与 §8 的人工检查覆盖。

## 6. 覆盖升级与回退

### 6.1 升级（保留数据）

1. 记录当前版本与 `runtime\modules\app.jar` 的 SHA256；确认软件已退出（无 `Uncle小说.exe`/`javaw.exe`）。
2. 备份 `%LOCALAPPDATA%\Programs\UncleNovel\conf\`（`core.db`、`conf.json`）到本地安全目录。
3. 用新 zip 解压后双击 `安装到本机.bat` → 提示已安装时选 `Y` 覆盖。
4. 安装后按 §4 自检 + §5 首启验证；确认书架与设置仍在。

### 6.2 回退（补丁级）

补丁只替换 `uncle-novel\runtime\modules\app.jar`，回退步骤：

```powershell
# 1) 结束所有相关进程
Get-Process javaw, "Uncle小说" -ErrorAction SilentlyContinue | Stop-Process -Force
# 2) 备份当前（出问题的新版）
Copy-Item "$env:LOCALAPPDATA\Programs\UncleNovel\runtime\modules\app.jar" "D:\备份\app.jar.新版"
# 3) 覆盖回上一版 app.jar
Copy-Item "D:\备份\app.jar.上一版" "$env:LOCALAPPDATA\Programs\UncleNovel\runtime\modules\app.jar" -Force
```

- 回退**不要动** `conf\core.db`、`conf\conf.json`（保留书架与设置）。
- 若整体回退到上一版产品包：先备份 `conf\`，再用上一版 zip 覆盖安装，最后把 `core.db`/`conf.json` 放回（版本升级产生的数据结构变化以 Lead 说明为准）。
- 升级/回退后都需重新执行 §4 自检项中的日志与启动检查。

## 8. 常见部署问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 解压报错/文件缺失 | 传输损坏、解压不完整 | 重新拷贝并校验 SHA256，完整解压 |
| 安装脚本窗口一闪而过 | 被杀软拦截/路径异常 | 在解压目录打开 CMD 执行 `安装到本机.bat` 看报错；确认杀软放行 |
| 快捷方式创建失败 | PowerShell 执行策略 | 用 `-NoProfile -ExecutionPolicy Bypass -File` 手工执行 |
| 安装完成但双击无反应 | 文件被隔离、进程残留、路径被移动 | 检查 `runtime\bin\javaw.exe` 是否存在；结束残留进程；从快捷方式启动 |
| 提示字体加载失败 | 安装/解压路径含中文或空格 | 移动到纯英文路径后重开；不移动已安装目录时改用默认安装路径 |
| 自检报 WMI 读取失败 | WMI 服务异常/权限 | 用管理员 PowerShell 重跑；仍失败则以人工清单核对 |
| 离线时联网功能全弹提示 | 预期行为 | 恢复网络或点「重试联网」；确认代理设置 |
| 杀软报警/删除文件 | Symantec 实时防护 | 将安装目录与 zip 加入排除；由 IT 确认策略 |
| 磁盘不足 | C 盘剩余 <10GB | 清理或改用 D 盘（安装目录仍固定在用户目录，需保证系统盘空间） |
| 远程会话下热键无效 | VNC/远程工具截获组合键 | 在本地控制台验证；或改老板键组合（见使用说明书 §5.3） |
