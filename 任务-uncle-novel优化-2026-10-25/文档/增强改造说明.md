# 增强改造说明（本地 TXT 快速阅读 + 分页增强）

> 目标：在不重新构建官方工程（上游已停更、打包插件/jfx-launcher 快照依赖已不可用）的前提下，
> 把旧版 4.x 的「本地 TXT 打开即读」体验合并进官方 5.0.44，并补齐「章节独立分页 + 页码显示」。
> 实现方式：**javac 补丁类 + 直接注入 app.jar（patch-module）**，业务代码改动最小化、可一键回退。

## 1. 总体架构

```
新增启动器（桌面快捷方式 / 本地TXT快速阅读.bat / 发送到）
   └─ javaw.exe --module-path runtime\modules ... -m com.unclezs.novel.app.main/com.unclezs.novel.app.main.QuickApp <文件|无>
        ├─ QuickApp（新增类，继承官方 App）
        │    ├─ init(): 精简初始化（跳过托盘/全局热键/自定义字体）
        │    ├─ getIndexView(): 轻量欢迎页（代替官方 HomeView，加快启动）
        │    ├─ 参数/文件选择框 → 打开本地 TXT
        │    ├─ 编码检测（EncodingDetect）+ 章节规则自动选择
        │    ├─ 后台线程：TxtLoader 建章节索引（落盘缓存）
        │    └─ Platform.runLater → navigate(ReaderView, Book) 进入官方阅读器
        ├─ TxtLoader（补丁类，官方类增强）
        └─ ReaderView（补丁类，官方类增强：标题栏页码/章号）

完整功能版仍走原入口：Uncle小说.exe（exe4j + jfx-launcher，启动器内嵌 jar；
  上一次任务已用 4 字节补丁去掉启动时的更新日志弹窗并本地化更新地址，本次未改动该链路）
```

## 2. 新增 / 修改清单

### 2.1 新增 `com.unclezs.novel.app.main.QuickApp`（约 250 行）

| 功能 | 实现要点 |
|---|---|
| 接收文件参数 | `getParameters().getRaw()`；无参数时打开 JavaFX `FileChooser`（过滤 `*.txt`，标题“选择要阅读的 TXT 文件”） |
| 精简启动 | 覆写 `init()`：只做 `Thread.setName("FX") + SettingManager.init()`，跳过 `TrayManager/HotkeyManager/FontsLoader`（本地快速阅读不需要，实测缩短启动） |
| 轻量首页 | 覆写 `getIndexView()` 返回 `SplashView`（一个 420×160 的 StackPane，含 `setMinSize` 防止 Stage 显示报错），避免官方 HomeView 的网络任务/侧栏初始化 |
| 打开文件 | 按 `url` 查重（同文件复用 Book 与阅读进度）→ `encoding = EncodingDetect.getEncode(file)` → 规则自动匹配 → 后台解析 toc → `bookDao.save/update` 入库 → `navigate(ReaderView.class, bundle)` |
| 章节规则自动选择 | 候选正则 4 组：`=== 标题 ===`、`第X章/节`、`《书名》第X章…`、`数字、标题`；读取文件头 512 KB 统计命中数，取最高且 ≥3 者；全不命中则用永不匹配规则触发官方「10 KB 虚拟分章」 |
| 体验 | 解析期间 `Toast.info("正在打开…")`，完成后 `Toast.success("已打开：…（N 章）")`；失败 `Toast.error` 并写日志 |

### 2.2 修改 `core.loader.TxtLoader`（官方类增强）

| 改动 | 说明 |
|---|---|
| **GB18030 统一解码** | `setBook()` 中把 `GB2312/GBK` 映射为超集 `GB18030`。原来按 GB2312 解码时，GB2312 外字符（下载站 TXT 里常见的 `=== 绗… ===` 乱码字符）会变成 `?`，导致章节名不可恢复 |
| **章节索引磁盘缓存** | 缓存路径 `caches/txt-index/v5_<md5(path)>_<size>_<mtime>_<charset>.json`（Gson 序列化 `List<Chapter>`）。`toc()` 命中即返回，实测 23 MB 文件二次解析 49 ms；版本号 `v5` 变更即自动失效旧缓存 |
| **乱码标题修复** | `repairMojibake()`：把“UTF-8 字节被 GBK 解读”的标题 `s.getBytes(GB18030)` 后再按 UTF-8 解码；丢弃替换符/私用区字符，含 ≥2 汉字才采用 |
| **标题清洗** | 去 `===` 包裹、去《书名》前缀、截断“正在手打中/免费阅读”水印；去除乱码残渣（`竄17` 等）；去开头章号；标题含 ≥2 汉字才保留 |
| **去重** | 只折叠「连续且原始标题完全相同」的行（下载站水印重复），修复失败的无标题章节全部保留（此前版本误删导致 331→102） |
| **目录名生成** | 统一为 `第N章 标题`（标题不可用则 `第N章`）；`序章/楔子/前言/后记/尾声/番外/终章` 保留原标题 |
| **正文去水印** | `loadContent()` 清洗：去掉整行 `===…===`、`本文件来自:`/`鏈功鏉ヨ嚜`、来源与广告行；合并 3 个以上空行 |
| **边界修复** | 最后一块内容无换行时 `lastIndexOf("\n")=-1` 导致 `substring(0,-1)` 崩溃（23 MB 文件必现）→ 改为 `lastN > 0` |

### 2.3 修改 `views.reader.ReaderView`（官方类增强，由 reader-patcher 交付）

- 新增 `updatePageTitle()`：`书名 · 章节名（第 x/y 页 · 章 n/m）`，写入 `StageDecorator.setTitle()`（即顶部标题栏）；
- 调用点：`displayPageByDebounce()`（每次翻页/重分页后）、`preChapter()/nextChapter()/toChapter()`（章切换后）；
- 原翻页、目录、TTS、设置面板、进度保存（`book.setCurrentPage/currentChapterIndex` + `bookDao.update`）逻辑未改；
- 每章独立分页沿用官方 `computePages()`（按窗口宽高×字号×行距×页宽测量文本），调整任一设置自动重新分页。

### 2.4 数据库补充（`conf/core.db` → `txt_toc_rule`）

新增一条规则，供「完整功能版 → 导入本地小说」流程识别下载站 TXT：

| id | name | rule | order |
|---|---|---|---|
| -19 | `=== 分隔标题（本地TXT）` | `^\s*={2,}.*={2,}\s*$` | 1 |

（仅追加，不修改原有 18 条规则；本版安装包 core.db 已含此规则，安装目录与交付包一致。）

## 4. 构建与部署（可复现）

```powershell
# 1) 构建：把 源码 中的 TxtLoader 复制并去 lombok，再叠加 工具\patch-src 中的补丁类，
#    用安装自带的 JDK11 javac 以 --patch-module 编译（需要 工具\lombok.jar 仅用于模块解析，运行不需要）
powershell -NoProfile -ExecutionPolicy Bypass -File "任务-uncle-novel优化-2026-10-25\工具\build-patch.ps1" -Clean
# 产物：C:\Temp\uq-build\classes\com\unclezs\novel\app\main\{QuickApp, core\loader\TxtLoader*, views\reader\ReaderView*}

# 2) 部署：把 class 写入安装目录 runtime\modules\app.jar（首次自动备份到 C:\Temp\uq-build\backup\app.jar.bak）
powershell -NoProfile -ExecutionPolicy Bypass -File "任务-uncle-novel优化-2026-10-25\工具\deploy-patch.ps1"
```

- 编译参数：`--module-path "<安装目录>\runtime\modules;<lombok.jar>" --patch-module com.unclezs.novel.app.main=<patch-src>`
  + `--add-exports javafx.controls/com.sun.javafx.scene.control.skin=com.unclezs.novel.app.main` 等（与 `app.modularity` 一致）。
- 说明：`app.jar` 的 `module-info` 含 `requires lombok static`，所以**编译期**必须把 lombok 放模块路径，**运行期**不需要。
- 回退：把 `C:\Temp\uq-build\backup\app.jar.bak`（或 `参考\app.jar.orig`）覆盖回 `runtime\modules\app.jar` 即可完全恢复官方行为；快捷方式删除即可。

## 5. 风险与限制

1. 补丁依赖官方类内部结构（`ReaderView`/`TxtLoader`/`BaseApplication`），若未来换版本需重新编译补丁；
2. 无参数启动用 JavaFX FileChooser，首次打开目录为当前用户目录；
3. 章节识别基于“行首正则 + === 分隔”，对结构完全混乱的 TXT 会退化为每 10 KB 虚拟分章；
4. 渲染、翻页动画、TTS、书源等官方业务逻辑未改，但本轮未做这些功能的回归测试；
5. 旧版 4.x 未做代码级合并（Java 8 + fxlauncher 架构与 5.x 模块化差异过大），采取“功能等价 + 数据可恢复”的合并方式。
