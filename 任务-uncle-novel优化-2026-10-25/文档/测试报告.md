## 5. 问题与修复记录（测试驱动）

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 打开 23.56 MB 文件报 `StringIndexOutOfBoundsException: begin 0, end -1` | TxtLoader 对「最后一块无换行」内容执行 `substring(0,-1)` | 边界判断改 `lastN > 0` |
| 2 | 章节名全为乱码/大量标题丢失 | 文件为 GB2312 被识别后按 GB2312 解码，GB2312 外字符变 `?`；且去重误删无标题章节 | 统一用 **GB18030 超集**解码；按「原始标题连续完全相同」去重；标题修复后仍失败则用序号兜底 |
| 3 | 地煞只有 102 章（应 331） | 去重逻辑把「标题修复失败（空标题）」的章节当重复删除 | 修正去重策略 |
| 4 | 翻页/标题不同步 | 自动化连发按键 + 100ms 防抖竞争 | 测试改为单次按键；真实用户单次操作无问题 |
| 5 | 快捷方式脚本中文乱码报错 | PS1 被写成无 BOM UTF-8，PowerShell 5.1 按 GBK 解析 | 统一转 UTF-8 BOM + CRLF 并复测 |

## 7. 局限

1. 打开耗时包含应用启动（JavaFX 冷启动 1.5–2.6 s），不是纯文件解析时间；二次打开依赖索引缓存。
2. UIA 文本采集有延迟，`打开秒` 为「能采集到正文」的时间，可能比人眼看到略晚。
3. 章节数受上游「=== 标题行」质量影响（作者话、广告被当成章节的情况已保留，未做语义过滤）。
4. 未覆盖：TTS 实际发声、书源联网下载、EPUB/MOBI 转换、多显示器、长时间稳定性。
5. 素材均为网络下载 TXT，章节标题存在不可逆的编码损坏（UTF-8 字节被 GBK 截断），本版已做可恢复部分的最大修复，个别标题仍可能有个别字缺失。

### 9.3 TTS 调研结论

**内置 8 个引擎全部可用，无需修改配置或替换 jar**

| 引擎 | 实测 | 说明 |
|---|---|---|
| 度博文（百度 POST http/https） | ✅ 200 / audio/mp3 / `FF F3 88 C4` 有效帧头 | 单次间隔 ≥2 s，避免代理限流（限流时 200 返回 JSON `err_no=529`，会被缓存成坏音频→“没声音”） |
| 思必驰 7 音色（dds.dui.ai） | ✅ 全部 200 / audio/mpeg / `FF F3` 有效帧头 | 无可见限流，单段 ≤200 字最稳（URL 上限约 280 字；250 字合成约 10.3 s 会超 app 10 s 读超时） |
| 默认 speaker=0 | ✅ 度博文 | 无需重置 conf.json |

- **应用内实测**：阅读器 → 设置 → 点「朗读」后 `caches\tts\` 生成 4 个 MP3（14–68 KB，首个文件头 `FF F3 88 C4` 有效帧），`log-error.log` 为空（截图 `测试结果\联网-TTS朗读.png`）。
- 曾测试的替代源（有道/搜狗/Google/百度 GET）均不可用（500/反爬/超时/鉴权），故不替换。
- 使用建议：短段落优先思必驰音色更稳；长段落用度博文；出现无声时切引擎或翻页重建缓存；仍无声等待 1 分钟后重试。
- 可选本地 TTS 服务（edge-tts/SAPI）已跑通但不推荐默认启用（需 Python 常驻服务），方案留存于 `参考\TTS\可选-本地TTS服务\`。

### 9.5 番茄小说下载攻坚（2026-10-27 增补，已解决）

**结论：免费书可下载，规则已内置；付费/受限书无正文。**

| 链路 | 方法 | 实测 |
|---|---|---|
| 搜索 | `novel.snssdk.com/api/novel/channel/homepage/search/search/v1/?aid=13&q=` | ✅ 10 条 |
| 目录 | `https://fanqienovel.com/api/reader/directory/detail?bookId=`（**无需签名/Cookie**，UA+Referer 即可） | ✅ 西游记 102 章、十日终焉 1496 章 |
| 正文 | `https://fanqienovel.com/reader/<itemId>` 阅读页 SSR `window.__INITIAL_STATE__` → `reader.chapterData.content` | ✅ 200，正文 HTML |
| 字体反爬 | 正文汉字被替换为 U+E3E8~U+E55B PUA 私密区码位；用社区 MIT 项目 `ckenkuo/fanqie-cdp-downloader` 的 charset 映射表在规则 `script` 内逐字还原（`bias=code-58344`，两套 mode 取残留最少） | ✅ PUA 残留=0 |
| 应用内验证 | 「解析下载」粘贴 `https://fanqienovel.com/api/reader/directory/detail?bookId=7345722444667161662`，应用内解析出 102 章目录（截图 `测试结果\联网-番茄解析-西游记.png`） | ✅ |
| 规则级验证 | `novel-analyzer.jar` 跑全链路：西游记（102 章/正文 7149 字，第二回可读）、诡秘剑主（268 章/2121 字）、十日终焉（1496 章/2381 字），PUA 残留均 0 | ✅ |
