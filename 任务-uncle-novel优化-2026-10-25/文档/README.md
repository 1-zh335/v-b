## 4. 安装

### 4.1 推荐方式：双击安装脚本（约 10 秒）

1. **解压**整个 zip 到任意可写目录（建议纯英文路径，如 `D:\Temp\Uncle小说-优化版`；解压后应能看到 §2.2 的 6 个顶层项：`uncle-novel` 文件夹 + 5 个脚本/说明文件）。
2. 双击 **`安装到本机.bat`**。
3. 脚本会依次执行：校验 `uncle-novel\Uncle小说.exe` 是否存在 → 用 `robocopy` 复制到 `%LOCALAPPDATA%\Programs\UncleNovel` → 调用 `初始化配置.ps1`（**仅当目标目录还没有 `conf\conf.json` 时**写入调优配置；覆盖安装不覆盖已有设置）→ 调用 `创建快捷方式.ps1` 创建桌面 + 开始菜单快捷方式 → 复制 `卸载.bat` 与 `使用说明.txt` 到安装目录。
4. **成功标志（缺一不可）**：

   | 成功标志 | 应看到的内容 |
   | --- | --- |
   | 复制成功 | `[OK] 程序文件已复制到: C:\Users\<你的用户名>\AppData\Local\Programs\UncleNovel` |
   | 初始化配置（全新安装） | `[OK] 已生成调优配置`；安装目录出现 `conf\conf.json`，内容含 `"fontSize": 20`、`"fontFamily": "Microsoft YaHei"`、`"lineSpacing": 0.2`、`"threadNum": 2`、`"retryNum": 1` |
   | 桌面快捷方式 | `[OK] 已创建快捷方式: C:\Users\<你的用户名>\Desktop\Uncle小说.lnk` |
   | 开始菜单快捷方式 | `[OK] 已创建快捷方式: C:\Users\<你的用户名>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Uncle小说.lnk` |
   | 附件复制 | `[OK] 卸载脚本与使用说明已放入安装目录` |
   | 收尾提示 | `安装完成！看到 [OK] 提示且桌面出现 "Uncle小说" 图标即为成功。` |
   | 目录检查 | 桌面出现「Uncle小说」图标；安装目录存在 `Uncle小说.exe` 与 `runtime\` |

   若中途出现 `[X] ...` 提示（例如 `[X] 未找到 uncle-novel 文件夹`、`[X] 文件复制失败`），说明压缩包未完整解压或目标目录不可写，按提示处理后再运行一次即可。**全新安装时整段输出应不少于 5 条 `[OK]`**（程序文件复制、初始化配置、桌面/开始菜单快捷方式、卸载脚本与说明），并看到最后的“安装完成！”提示。

5. **覆盖安装（升级/修复）**：若检测到已安装，脚本会提示：
   `[!] 检测到已安装: ...\UncleNovel` + `是否覆盖安装（保留书架数据 conf\core.db 与设置 conf\conf.json）`。
   选择 `Y` 后，**保留** `conf\core.db`（书架/书源/规则/下载历史）与 `conf\conf.json`（设置），只覆盖程序文件；选择 `N` 则取消。保留 `conf\conf.json` 意味着你之前调过的字体/阅读参数不会丢（也意味着覆盖安装不会套用调优默认值）。

### 4.2 备用方式：绿色手动使用

不想安装、只想临时试用时：

1. 把 zip 内的 `uncle-novel` 文件夹整体复制到任意**纯英文**路径（例如 `D:\Apps\UncleNovel`）。
2. 右键 `Uncle小说.exe` → 发送到 → 桌面快捷方式；打开快捷方式属性，把 **「起始位置」设为该文件夹**。
3. 双击快捷方式启动。

> ⚠️ 不要直接双击别的目录里的 exe、也不要让「起始位置」留空：本软件的数据目录 = **进程当前工作目录**，起始位置不对会导致设置/书架写到其他目录，看起来像「设置丢失」。

### 4.3 为什么安装在 `%LOCALAPPDATA%\Programs\UncleNovel`

| 原因 | 说明 |
| --- | --- |
| 纯 ASCII 路径 | 内置 PingFang 字体在**含中文的路径**下无法被 JavaFX 加载（原版日志会反复报 `加载pingfang-simple-bold.ttf字体失败`）；纯英文路径下字体正常加载、报错消失 |
| 当前用户可写 | 无需管理员权限，不触发 UAC，卸载无需提权 |
| 与快捷方式配合 | 快捷方式「起始位置」= 安装目录，保证数据始终写在安装目录内 |

### 4.4 安装后自检（建议做一遍）

1. 双击桌面「Uncle小说」图标，主窗口出现，左侧导航「小说书架 / 搜索小说 / 全网搜书 / 寻找有声 …」可点击。
2. **不再**出现「当前版本 - V5.0.44」更新日志对话框（原版每次启动必弹）。
3. 打开安装目录 `logs\log-error.log`，内容为**空**（0 字节；官方原版每次启动会记录一条约 120 字节的字体错误）；`conf\font.css` 内容是 `.root{-fx-font-family: 'Microsoft YaHei';}`。
4. 若是**全新安装**：打开 `conf\conf.json`，应能看到 `"fontSize": 20`、`"fontFamily": "Microsoft YaHei"`、`"lineSpacing": 0.2`、`"threadNum": 2`、`"retryNum": 1`（安装脚本已写入调优配置；覆盖安装则保留你原有设置）。
5. 打开「软件设置」页，应显示：系统字体 = Microsoft YaHei、单任务线程数量 = 2、失败重试次数 = 1、下载文件保存位置 = 安装目录下 `downloads`（最终验收截图见 `任务-uncle-novel优化-2026-10-25\截图\最终验收\`）。

## 5. 启动与退出

| 操作 | 方法 |
| --- | --- |
| 启动 | 双击桌面 / 开始菜单的「Uncle小说」快捷方式 |

## 6. 数据位置与备份 / 迁移

**所有数据都在安装目录内**，这是本软件的设计（源码 `ResourceManager.WORK_DIR = new File(".")`，即进程当前工作目录）。

| 路径（相对安装目录） | 内容 | 重要性 |
| --- | --- | --- |
| `conf\conf.json` | 软件设置：主题、字体、阅读参数、下载参数、代理、热键等 | ★★★ 安装脚本首次安装时生成（手动/绿色使用则首次启动生成） |
| `conf\core.db` | SQLite 数据库：书源（`search_engine`）、TXT 目录规则（`txt_toc_rule`）、书架（`book`）、下载历史等 | ★★★ 出厂自带，请勿删 |
| `conf\app.json` | 启动器资源清单 + 更新地址（本优化版已改为本地快速失败地址，**勿改坏**） | ★★ |
| `conf\launcher.vmoptions` | JVM 参数（本优化版已调优） | ★★ |
| `conf\font.css` | 界面字体样式，由软件自动生成 | ★ |
| `conf\jul.properties` / `conf\rules.json` | JUL 日志配置 / 自定义规则（自动生成） | ★ |
| `fonts\` | 内置字体（PingFang） | ★★ |
| `logs\` | 运行日志（`log-error.log` 看错误、`log-system.log` 看启动器） | ★ |
| `downloads\` | 下载的小说文件 | ★★★（自己下载的内容） |
| `caches\` | 缓存（可删，删后会重建） | — |
| `backup\` | 内置备份输出目录 | ★★ |
| `plugins\` | 插件目录（当前为空/按需生成） | ★ |
| `bin\kindlegen.exe` | MOBI 转换组件（仅 Windows 版保留） | ★ |

### 6.1 备份

1. **先正常退出**程序（含托盘退出），确认任务管理器里没有 `Uncle小说.exe`。
2. 把**整个安装目录**复制/压缩保存（至少包含 `conf\` 与 `downloads\`）。
3. 建议同时保留 `使用说明.txt` 与第 10 节的 SHA256，便于日后核对版本。

### 6.2 恢复

把备份的整个目录覆盖回原安装位置（保持纯英文路径），或按 §4.2 在别处放置并重建快捷方式。

### 6.3 迁移 / 换机

1. 退出程序 → 把整个安装目录复制到新机器（**纯英文路径**）。
2. 在新机器上运行 zip 内 `安装到本机.bat`（先安装到默认位置），再用旧目录中的 `conf\` 与 `downloads\` 覆盖新安装目录中的同名内容，即可保留书架、书源、设置与下载的书。
3. 或按 §4.2 手动放置后重建快捷方式（必须设置「起始位置」）。

> 提示：迁移/备份**不需要**重新安装运行时（`runtime\` 就在安装目录里）。

## 7. 优化点一览

| 编号 | 优化项 | 做了什么 | 实测效果 | 回退方法 |
| --- | --- | --- | --- | --- |
| A | **移除每次启动的更新日志弹窗** | 对 `runtime\modules\app.jar` 里 `App.start` 调用 `UpdateUtils.checkForUpdate(stage)` 的 4 字节字节码做等长 NOP 替换（`2B B8 00 1D` → `00 00 00 00`） | 原版每次启动必弹「当前版本 - V5.0.44」；优化版不再弹。UIA 元素数 83 → 71 | 用 `参考\app.jar.orig` 覆盖回 `runtime\modules\app.jar` |
| B | **更新检查快速失败** | `conf\app.json` 中 `"url"` 由 `https://update-uncle-novel.unclezs.com/novel/prod/` 改为 `http://127.0.0.1:1/` | 不再等待已失效域名的 DNS 超时（连接被本机立即拒绝，启动器失败后继续启动，功能不受影响） | 用 `参考\app.json.orig` 覆盖回 `conf\app.json` |
| C | **JVM 参数调优** | `conf\launcher.vmoptions` 由 1 行扩充为 6 行：`-Xms128m`、`-Xmx1024m`、`-XX:MaxMetaspaceSize=256m`、`-XX:ReservedCodeCacheSize=128m`、`-Dprism.lcdtext=false` 等 | `jcmd VM.flags / system_properties` 确认全部生效；堆/元空间有上限约束，避免极端膨胀；关闭 LCD 次像素渲染后中文界面文字边缘更干净（无彩边） | 用 `参考\launcher.vmoptions.orig` 覆盖回 `conf\launcher.vmoptions` |
| D | **字体加载失败修复（部署层面）** | 安装到纯 ASCII 路径 `%LOCALAPPDATA%\Programs\UncleNovel` | 原版日志 16 条 `加载pingfang-simple-bold.ttf字体失败`；优化版 `logs\log-error.log` 为 0 字节，错误消失 | 移回含中文路径会复现日志报错（功能不受影响），无需回退 |
| E | **体积裁剪** | 删除 Windows 用不到的两个转换组件：`bin\kindlegen`（Mac，23,163,488 字节）、`bin\kindlegen_linux`（Linux，28,752,467 字节），保留 `bin\kindlegen.exe` | 安装体积 **196.1 MB → 146.6 MB（约 -50 MB，-25.6%）** | 从 `1-原版` 或官方 zip 把两个文件拷回 `bin\` |

## 8. 常见问题（FAQ）

**Q1 双击快捷方式没反应 / 闪退？**
- 先看任务管理器：程序是**单实例**，若已有 `Uncle小说.exe` 在后台（例如最小化到托盘），再次双击只会尝试唤起窗口。结束该进程后再启动。
- 仍失败：打开安装目录 `logs\`，把 `log-error.log`、`log-system.log` 最后几十行发出来定位；常见原因是解压不完整、路径权限不足、被杀软拦截（见 Q10）。

**Q2 启动后界面「卡住」/没有主窗口？**
- 首次启动需要初始化 JavaFX 与缓存，可能比后续启动慢（实测主窗口可交互约 5 秒，机器负载高时更久），稍等即可。
- 若 30 秒仍无窗口，见 Q1 查日志。

**Q3 设置有丢失 / 书架空了？**
- 确认是**从快捷方式**启动，且快捷方式「起始位置」= 安装目录（右键快捷方式→属性→起始位置）。起始位置错误会让程序把数据写到别处。
- 覆盖安装时是否选择了 `N`（取消）？升级请选 `Y`，脚本会保留 `conf\core.db` 与 `conf\conf.json`。
- 若是整目录搬迁，确认旧 `conf\` 已一起带过去。

**Q4 搜索不到书 / 书源全失效？**
- 上游官方书源站已停止服务（对应上游 issue #48），程序内置的 3 条书源多数已不可用，这不是本优化造成的。
- 可在「书源管理」中导入社区维护的 gitee 书源 JSON（例如 `https://gitee.com/curioucs/novel/raw/master/book_text.json`，对应上游 issue #100），或自行编写/导入书源规则。
- ⚠️ 第三方书源的内容来自第三方网站，请自行判断来源合法性与版权风险，本项目不提供、不分发任何小说内容。

**Q5 日志出现「加载pingfang-simple-bold.ttf字体失败」/ 界面字体不对？**
- 含义：安装路径**含中文字符**，JavaFX 的 `Font.loadFont` 无法加载该路径下的字体文件（字体文件本身是好的，放到 `C:\Temp` 等纯英文路径可正常加载为 `.PingFang SC`）。
- 处理：把整个安装目录移动到纯英文路径（例如 `C:\Users\<你>\AppData\Local\Programs\UncleNovel`），或直接运行 `安装到本机.bat` 重新安装到默认位置；然后重建快捷方式（起始位置=新目录）。
- 该错误只影响内置字体加载，程序会自动回退系统字体，不影响阅读等主要功能。

**Q6 每次启动都弹「当前版本 - V5.0.44」更新日志？**
- 这是**官方原版**行为：启动器检查更新失败时仍以 `hasNew=true` 传参，应用随后弹出更新日志对话框。
- 本次优化已消除该弹窗（见 §7-A）。如果优化版仍弹出：
  1) 你可能启动的是旧目录/旧安装（例如误用了 `1-原版` 或官方包）：确认快捷方式目标为 `%LOCALAPPDATA%\Programs\UncleNovel\Uncle小说.exe`；
  2) 用 §10 的 SHA256 核对 `runtime\modules\app.jar` 是否为本优化版。

**Q7 日志里有一条「更新失败 Manifest加载失败: http://127.0.0.1:1/conf/app.json」正常吗？**
- **正常，属预期**。更新服务器已停用，本优化版故意把检查地址改为本机 `127.0.0.1:1`，让连接立即被拒而不再等待 DNS 超时；启动器记录一条「更新失败」后继续启动应用，不影响任何功能。
- 若你看到的是原域名 `update-uncle-novel.unclezs.com` 的超时错误，说明该文件还是原版（回退过或用了旧目录），可按 §7-B / §10 核对。

**Q8 内存占用 700 多 MB、启动要好几秒，正常吗？**
- 正常。JavaFX 应用初始化本身偏重；实测常驻内存约 700–740 MB（两版相当）。主窗口可交互时间：原版 **4.76–6.33 秒**（中位 6.33 秒）、优化版 **4.96–5.20 秒**（中位 5.20 秒），两版同量级（各 3 次交替、机器有后台负载，样本小，仅供参考）。
- `-Xmx1024m` 是**上限约束**，不是预占 1 GB；JVM 参数调优主要价值是「可预测、防极端」，不会让启动明显变快（瓶颈在 JavaFX 初始化）。
- 可关闭其他占内存程序；不建议再加大 `-Xmx`（收益低、RSS 更高）。

**Q9 125% 高 DPI 下界面布局错乱？**
- 这是上游已知问题（issue #69），本优化未修改任何布局代码。可尝试在「软件设置」里调整界面缩放/主题，或把系统缩放设为 150%（本优化实测 150% 正常）。

**Q10 杀毒软件报毒 / 拦截安装脚本？**
- 主程序由 exe4j 生成（jar 内嵌进 exe、单实例），这类打包方式常被启发式引擎误报；`安装到本机.bat` 只是 `robocopy` + 创建快捷方式，不含联网行为。
- 处理：把安装目录与 zip 加入杀软信任；或先核对 §10 的 SHA256 与官方原始 zip 来源。若无法接受，请改用官方安装包（但那样就没有本优化）。

**Q11 为什么不能像以前一样自动更新到新版本？**
- 上游已停更（最后发布 v5.0.44，2024-01-18），且更新域名 `uncle-novel.unclezs.com` / `update-uncle-novel.unclezs.com` / `app.unclezs.com` 均已 DNS 解析失败。本优化版不会收到官方更新，也不建议用官方 `Setup.exe` 覆盖安装（会覆盖掉本优化的程序文件）。

**Q12 动画偶尔卡顿？**
- 上游已知问题（issue #60），与本次优化无关；本优化未改动动画/渲染逻辑（仅关闭 LCD 次像素渲染，属字体清晰度设置）。

## 9. 卸载

### 9.1 使用卸载脚本（推荐）

1. **先正常退出程序**（含托盘退出；任务管理器确认无 `Uncle小说.exe`）。
2. 双击运行**安装目录下的 `卸载.bat`**（压缩包内也有一份同样的 `卸载.bat`）。
3. 按提示确认（`choice /c YN`）：
   - 第一步会删除**桌面 + 开始菜单**的「Uncle小说」快捷方式，并输出 `[OK] 已删除 ...\Uncle小说.lnk`；
   - 第二步询问「是否同时删除安装目录（含书架/设置/下载，不可恢复）」：选 `Y` 会 `rd /s /q` 删除安装目录；选 `N` 保留目录（只删快捷方式）。
4. 卸载完成。

> 删除前请先备份 `conf\core.db`（书架/书源）、`conf\conf.json`（设置）、`downloads\`（下载的书），一旦删除不可恢复。

### 9.2 手动卸载

1. 退出程序，删除桌面与开始菜单的「Uncle小说」快捷方式。
2. 删除安装目录 `%LOCALAPPDATA%\Programs\UncleNovel`。
3. 无注册表项残留；本优化版不做系统级安装（不写服务/计划任务/开机启动）。

### 9.3 回到官方原版

删除安装目录与快捷方式后，把 `任务-uncle-novel优化-2026-10-25\1-原版\uncle-novel`（官方 win.zip 解压）复制到任意目录，按 §4.2 建快捷方式即可；或直接使用官方 `Setup.exe` 安装。
