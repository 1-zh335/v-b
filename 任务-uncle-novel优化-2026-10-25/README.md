## 二、做了什么（一句话版）

**v1（2026-10-25）安装后优化**：官方 v5.0.44 便携版 → 安装到 ASCII 用户目录 + 5 项安装后优化（**去除每次启动的更新日志弹窗**、更新检查秒失败、JVM/渲染参数、字体错误修复、体积裁剪 196.1→146.6 MB）+ 调优默认阅读配置 + 安装/卸载/快捷方式脚本 + 端到端验证。

**v3（2026-10-27）联网增强 + 书架增强**：

- 联网书源：`conf\rules.json` 内置 4 条实测可用书源（书趣阁 / 365小说网 / 红袖 / **番茄可下载**），应用内「搜索小说」搜“斗破苍穹”实时出结果、「解析下载」可解析真实目录；4 站下载链路由 app 自带解析库端到端实测（正文 774–7149 字）。
- **番茄小说免费书已可下载**：目录 API（`reader/directory/detail?bookId=`，无需签名）+ reader 页 SSR + PUA 字体解密（残留 0）；付费/受限书 reader 页 404 不可得。报告：[`参考\网络规则\fanqie\番茄下载攻关报告.md`](参考/网络规则/fanqie/番茄下载攻关报告.md)。
- **有声小说书源不内置**：18 条社区有声规则逐站实测 0 条能拿可播放音频（15 站失效；喜马拉雅需 webtk/xm-sign、酷我需 CSRF、懒人需 token）；替代方案 = 阅读器内置 TTS 朗读（8 引擎可用）。报告：[`参考\网络规则\audio\有声书源调研报告.md`](参考/网络规则/audio/有声书源调研报告.md)。
- 搜索引擎：应用内「全网搜书」百度 WebView 渲染真实搜索结果（必应可用；谷歌受本机网络限制）。
- TTS 朗读：内置 8 个引擎实测全部可用，应用内朗读生成有效 MP3，无需改配置。
- 书架：书名常显 + 按书名自动生成同名封面（7 本素材全部验证，截图 [`截图\书架增强\`](截图/书架增强)）。
- 交付包 `书源-可选\` 含全部候选书源、番茄报告、有声报告与 TTS 报告。

**v2（2026-10-27）本地 TXT 阅读增强**：在不重编译官方工程的前提下，用 `javac --patch-module` 向 `app.jar` 注入补丁类，实现 **本地 TXT 打开即读（QuickApp）+ 章节自动识别与乱码修复 + 章节索引缓存 + 每章独立分页与页码显示**，并新增「本地TXT快速阅读」快捷方式/拖拽/右键发送到；用用户提供的 7 个素材（2.4–23.6 MB）全部实测通过。

## 五、回退方法

1. **卸载本优化版**：运行 `%LOCALAPPDATA%\Programs\UncleNovel\卸载.bat`（可选删除安装目录；删除前先备份 `conf\core.db`、`conf\conf.json`、`downloads\`）。
2. **恢复官方原版**：把 [`1-原版\uncle-novel`](1-原版) 整体复制到任意 ASCII 路径双击 `Uncle小说.exe` 即可（该目录是官方原包解压的纯净副本）。
3. **回退 v2 本地 TXT 增强**：把 `参考\app.jar.官方-优化版-原始备份`（即 v1 的 app.jar）覆盖回 `runtime\modules\app.jar`，并删除「本地TXT快速阅读」快捷方式即可。
4. **回退单项 v1 优化**：`参考\` 下有 `app.jar.orig`（官方原版 app.jar）、`app.json.orig`、`launcher.vmoptions.orig`、`字体备份\pingfang-simple-bold.ttf`，按 修改说明.md 的「回退」列替换即可。
