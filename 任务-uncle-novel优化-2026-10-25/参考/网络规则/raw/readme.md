# novel

#### 介绍
随缘更新Uncle小说书源


#### 使用说明

1.  文本书源：https://gitee.com/curioucs/novel/raw/master/book_text.json
2.  防盗书源：https://gitee.com/curioucs/novel/raw/master/%E9%98%B2%E7%9B%97%E4%B9%A6%E6%BA%90.json
2.  有声书源：https://gitee.com/curioucs/novel/raw/master/book_music.json
3.  音频链接重定向的不可播放（跳两次）
4.  音频源以分组作为注释，写明了哪些源可播放，哪些源只能下载。
5.  书源出问题，可以提出issue，记得标明是什么书源
6.  有想加入的源的网站，可以issue，表明是什么网站
