# 可选：本地 TTS 服务（edge-tts / Windows SAPI）

> **定位：备选方案，本次不建议默认启用。** 内置 8 个引擎当前实测可用（见 `..\TTS调研报告.md`），
> 本服务只在将来百度/思必驰公开接口失联、或需要更自然音色/超长文本/无限流时使用。

## 它解决什么

Uncle小说 5.0.44 的 `TTSConfig.getFormattedParams()` 会对 `{{text}}` **二次百分号编码**，服务端需解码两次才能拿到原文。
本服务把 app 发来的串 `unquote` 两次还原原文，再调用 TTS 合成，直接返回 `audio/mpeg`（edge）或 `audio/wav`（SAPI），
app 的 `Http.bytes` + JavaFX `MediaPlayer` 可直接播放（已用 app 自身代码路径端到端实测通过）。

## 环境要求

- 方案 A（音质好，需联网）：Python 3 + `pip install edge-tts`（实测 7.3.1，含 8 个 zh-CN 音色）
- 方案 B（离线，音色机械）：Windows 自带 SAPI 中文语音（本机为 `Microsoft Huihui Desktop`），只需 PowerShell

## 启动（最小方式）

```bat
:: 方案 A：edge-tts（先装依赖）
py -3 -m pip install edge-tts
py -3 local_tts_server.py --port 18523 --backend edge --voice zh-CN-XiaoxiaoNeural

:: 方案 B：离线 SAPI
py -3 local_tts_server.py --port 18524 --backend sapi
```

本机已建好虚拟环境时也可直接：`工具\tts-test\.venv\Scripts\python.exe local_tts_server.py --port 18523`

自检：浏览器访问 `http://127.0.0.1:18523/health` 应返回 `ok`；`http://127.0.0.1:18523/tts?text=%E6%B5%8B%E8%AF%95` 应返回 MP3。

## app 侧配置（追加到 tts.json 末尾）

```json
{
  "params": {
    "url": "http://127.0.0.1:18523/tts?text={{text}}",
    "method": "GET"
  },
  "name": "本地 Edge TTS 晓晓"
}
```

- 先启动服务，再启动 Uncle小说；
- 必须把上面的项追加在**末尾**，不要改动前 8 项顺序（旧配置 `reader.speaker` 是下标）；
- 服务未启动时该引擎会连接失败（`ConnectException`），切回内置引擎即可。

## 已验证数据（app 真实路径）

| 后端 | 短文本（4 字） | 130 字 | 音频头 |
|---|---|---|---|
| edge-tts | 10368 B MP3，耗时 2.3s | 166608 B MP3，耗时 2.0s | `FF F3 64 C4` |
| SAPI | 91948 B WAV，耗时 0.4s | 1912230 B WAV，耗时 0.7s | `RIFF/WAVE` |

## 注意

- 端口被占用时换 `--port`，并同步修改 app 配置；
- edge-tts 依赖微软在线服务，网络不通时自动改用 `--backend sapi`；
- 服务日志写入同目录 `local_tts_requests.jsonl`（便于排查）；
- 仅个人阅读使用，请勿将合成音频二次分发。
